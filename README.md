# TESSWANG-AI-SKILLS
TESSWANG Enterprise AI Skills & Agent Knowledge Base

## 项目简介

TESSWANG 企业自动化系统：覆盖商品资料库、平台新品监测、同款比价、中文日报与内容发布流程。
全部执行程序仅依赖 Python 标准库，数据与凭据保留在私有环境，本仓库只保存代码与文档。

## 目录

- `scripts/` — 执行程序
- `docs/` — 架构说明、字段字典、使用文档
- `tests/` — 独立测试夹具与测试脚本

## 快速开始

```bash
python3 tests/test_parser.py
```

详见 [docs/usage.md](docs/usage.md)。

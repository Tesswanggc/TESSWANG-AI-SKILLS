# TESSWANG 企业自动化系统 — 架构说明

## 角色分工

| 组件 | 职责 |
|---|---|
| 豆包（桌面应用/浏览器） | 理解任务、浏览器操作、结果解释、人工介入（登录/验证码/权限） |
| 执行程序（Python，标准库） | 定时调度、数据整理、去重、规则校验、价格计算、日报生成、日志与失败恢复 |
| GitHub 公开仓库 | 代码、技能说明、配置模板、使用文档 |
| 私有工作目录（本地） | 账号凭据、Cookie、Token、客户信息、非公开价格、原始经营数据、运行状态 |

## 数据边界

- 公开仓库**禁止**提交：账号密码、Cookie、Token、客户信息、非公开价格、原始经营数据。
- 真实业务数据与测试数据分目录存放：`data/` 为真实数据，`tests/` 为独立夹具。
- 无法核验的字段留空并在“缺失说明”注明原因，禁止臆造。

## 目录结构

```
tesswang-automation/
├── scripts/            # 执行程序
├── docs/               # 架构、字段字典、使用文档
├── tests/              # 测试夹具与测试脚本（测试数据）
├── data/
│   ├── raw/            # 原始接口响应
│   ├── product_master/ # 商品主表（CSV + 规范化 JSON）
│   ├── monitoring/     # 新品监测结果与去重状态
│   ├── price_compare/  # 比价样本与计算结果
│   └── reports/        # 每日日报
└── state/              # 状态、日志、恢复记录
```

## 失败处理原则

- 访问失败：有限重试 + 指数退避，不无限循环，不绕过验证码或访问限制。
- 每种问题最多尝试三种有依据的方案；仍失败则记录阻塞，继续不依赖它的工作。
- 严格区分三种状态：没有合格结果 / 证据不足 / 访问失败。
